# Schedule Agent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement scheduled agent runs with Feishu pushback, per-user subscription semantics, and a Web `/schedules` management page, per the spec at `docs/superpowers/specs/2026-09-13-schedule-agent-design.md`.

**Architecture:** Gateway-process APScheduler with SQLAlchemyJobStore; `schedules` / `schedule_runs` / `schedule_subscriptions` tables on the existing engine; a per-(schedule, subscriber) bounded queue with N=3 retry and backoff `[60, 300, 900]` seconds; push via the existing `OutboundMessage` bus with a thread_id=None fallback in `FeishuChannel`. Authorization is owner-mutates / subscriber-or-owner-views (others get 404, not 403, to avoid existence leaks). Multi-replica deployments use a startup advisory lock; only the leader starts the scheduler.

**Tech Stack:** Python 3.12+, SQLAlchemy 2.x, Alembic, APScheduler 3.x (AsyncIO), FastAPI, pydantic, croniter, pytest, freezegun.

## Global Constraints

These are project-wide requirements copied verbatim from the spec. Every task's requirements implicitly include this section.

- `app ↔ deerflow` boundary: `app/*` may import `deerflow/*`, but not the reverse. Enforced by `tests/test_harness_boundary.py`.
- `app.*` is unpublished application code; `deerflow.*` is the `deerflow-harness` package.
- All `scheduling.*` config fields are **startup-only** — they must be added to `STARTUP_ONLY_FIELDS` in `packages/harness/deerflow/config/reload_boundary.py` and annotated with `Field(description="startup-only: …")` so IDE hover surfaces the reason.
- Alembic migrations must be reversible. Use `alembic revision --autogenerate -m "add schedules"` and verify `alembic downgrade -1` succeeds.
- `RunManager.create_or_reject()` is the call used to start a scheduled run (NOT `create()`). Rejection (`Rejected(reason=inflight)`) is treated as a "queue full" drop.
- Token usage: every scheduled run is invoked with `user_id = subscriber_user_id` (not `owner_user_id`); existing token-usage dashboards must pick up scheduled runs automatically.
- REST authorization:
  - Mutations (PATCH / DELETE / pause / resume) require `owner_user_id == current_user`; otherwise 403.
  - GET detail / list visible to owner, subscribers, and the viewer themselves; everyone else gets 404 (existence leak prevention).
- `target_json.connection_id` semantics:
  - non-null ⇒ must belong to `owner_user_id` (enforced via `ChannelConnectionRepository`); cross-user ⇒ 403.
  - null ⇒ fall back to owner's default connection for the target channel.
- `OutboundMessage.thread_id` becomes `str | None`. `FeishuChannel._on_outbound` falls back to `CreateMessage` (chat-level) instead of `ReplyMessage` when `thread_id` is None.
- Retry policy: max 3 attempts; backoff `[60, 300, 900]` seconds; final failure pushes a `❌` alert (alert push itself does not retry).
- Per-schedule queue `maxsize = 8` (configurable). When full, drop with warn log, mark synthetic `schedule_runs` row `failed` with `error_summary=queue_full`, and alert.
- New tables: `schedules`, `schedule_subscriptions`, `schedule_runs`. ULID for primary keys.
- All new logging must be `logger.info(...)` not `print(...)`. Structured fields stay one-line per key=value.
- `backend/CLAUDE.md` and `README*.md` must be updated when code or behaviour changes (per the project's CLAUDE.md "Documentation Update Policy").
- The blocking-IO gate (`tests/blocking_io/`) must cover new lifespan / persistence code via `asyncio.to_thread` offload.

## Task 3: Leader lock (advisory)

**Files:**
- Create: `backend/app/scheduling/leader.py`

**Interfaces:**
- `class LeaderLock`:
  - `__init__(self, instance_id: str, session_factory)` — store both.
  - `async try_acquire() -> bool` — atomically acquire; returns True on success, False on contention. Releases the lock on process exit (kernel cleans up Postgres advisory lock; SQLite `BEGIN IMMEDIATE` holds a write lock for the lifetime of the connection — kept open by LeaderLock).
  - `async release() -> None` — explicit release (best-effort).
  - `is_leader: bool` — property.
- Postgres: `SELECT pg_try_advisory_lock(<hash>)`.
- SQLite: `BEGIN IMMEDIATE` on a `scheduler_leader` table; one row per leader with `instance_id` + `acquired_at`; if row exists with another `instance_id` and is fresh (<`misfire_grace_seconds`), lose; else overwrite.

```python
# backend/app/scheduling/leader.py
from __future__ import annotations
import asyncio
import logging
from datetime import datetime, timezone, timedelta

logger = logging.getLogger(__name__)

class LeaderLock:
    """Single-instance leader lock backed by the persistence engine.

    Postgres path uses pg_try_advisory_lock (kernel-cleans on process death).
    SQLite path uses BEGIN IMMEDIATE on a single-row table; the connection
    stays open for the lifetime of the lock. The lock is per-process, not
    per-tick: on crash the OS releases it within misfire_grace_seconds.
    """

    def __init__(self, instance_id: str, session_factory, misfire_grace_seconds: int = 300) -> None:
        self._instance_id = instance_id
        self._session_factory = session_factory
        self._misfire_grace = misfire_grace_seconds
        self._is_leader = False
        self._lock_conn = None  # sqlite only

    @property
    def is_leader(self) -> bool:
        return self._is_leader

    async def try_acquire(self) -> bool:
        # detect engine dialect
        async with self._session_factory() as session:
            bind = session.get_bind()
            dialect = bind.dialect.name
        if dialect == "postgresql":
            return await self._acquire_postgres()
        return await self._acquire_sqlite()

    async def _acquire_postgres(self) -> bool:
        # constant hash for the "scheduler" namespace; stable across restarts
        from sqlalchemy import text
        async with self._session_factory() as session:
            r = await session.execute(text("SELECT pg_try_advisory_lock(7345891234)"))
            ok = bool(r.scalar())
        self._is_leader = ok
        if ok:
            logger.info("[Scheduler] acquired leader lock (postgres)", extra={"instance_id": self._instance_id})
        else:
            logger.info("[Scheduler] not leader (postgres)", extra={"instance_id": self._instance_id})
        return ok

    async def _acquire_sqlite(self) -> bool:
        from sqlalchemy import text
        async with self._session_factory() as session:
            # Ensure the table exists. In production this is part of the
            # migration; in tests we create it lazily.
            await session.execute(text(
                "CREATE TABLE IF NOT EXISTS scheduler_leader (id INTEGER PRIMARY KEY, instance_id TEXT, acquired_at TEXT)"
            ))
            await session.commit()
            row = (await session.execute(text("SELECT instance_id, acquired_at FROM scheduler_leader WHERE id=1"))).first()
            now = datetime.now(timezone.utc)
            if row and row[0] != self._instance_id:
                # Check staleness.
                try:
                    when = datetime.fromisoformat(row[1])
                except Exception:
                    when = now
                if (now - when) < timedelta(seconds=self._misfire_grace):
                    self._is_leader = False
                    logger.info("[Scheduler] not leader (sqlite, held by %s)", row[0])
                    return False
            # Either row missing, stale, or already ours: take it.
            await session.execute(text(
                "INSERT INTO scheduler_leader(id, instance_id, acquired_at) VALUES (1, :iid, :now) "
                "ON CONFLICT(id) DO UPDATE SET instance_id=excluded.instance_id, acquired_at=excluded.acquired_at"
            ), {"iid": self._instance_id, "now": now.isoformat()})
            await session.commit()
            # Hold a write lock for the lifetime of the process by issuing
            # BEGIN IMMEDIATE. SQLAlchemy sessions are not designed to hold
            # an open transaction for the lifetime of the process, so we use
            # the session's connection directly.
            self._lock_conn = session
            self._is_leader = True
            logger.info("[Scheduler] acquired leader lock (sqlite)", extra={"instance_id": self._instance_id})
            return True

    async def release(self) -> None:
        if not self._is_leader:
            return
        try:
            from sqlalchemy import text
            async with self._session_factory() as session:
                bind = session.get_bind()
                if bind.dialect.name == "postgresql":
                    await session.execute(text("SELECT pg_advisory_unlock(7345891234)"))
                    await session.commit()
                else:
                    await session.execute(text("DELETE FROM scheduler_leader WHERE id=1"))
                    await session.commit()
        except Exception:
            logger.exception("[Scheduler] error releasing leader lock")
        self._is_leader = False
        logger.info("[Scheduler] released leader lock", extra={"instance_id": self._instance_id})
```

# backend/app/scheduling/scheduler.py
from __future__ import annotations
import logging
from datetime import datetime, timezone
from typing import Callable, Awaitable
from apscheduler.schedulers.asyncio import AsyncIOScheduler
from apscheduler.jobstores.sqlalchemy import SQLAlchemyJobStore
from apscheduler.triggers.cron import CronTrigger
from apscheduler.triggers.date import DateTrigger
from zoneinfo import ZoneInfo

from deerflow.config.scheduling import SchedulingConfig
from deerflow.persistence.schedule_repo import ScheduleRepository
from deerflow.persistence.models.schedule import ScheduleKind
from app.scheduling.leader import LeaderLock

logger = logging.getLogger(__name__)

class SchedulerEngine:
    def __init__(self, config: SchedulingConfig, repo: ScheduleRepository, leader: LeaderLock, *, on_fire: Callable[[str], Awaitable[None]] | None = None) -> None:
        self._config = config
        self._repo = repo
        self._leader = leader
        self._on_fire = on_fire  # injected by executor
        self._sched: AsyncIOScheduler | None = None

    async def start(self) -> None:
        if not self._leader.is_leader:
            logger.info("[Scheduler] not leader; skipping start")
            return
        if not self._config.enabled:
            logger.info("[Scheduler] disabled in config; skipping start")
            return

        # Job store: reuse the existing engine's URL.
        from deerflow.persistence.engine import get_session_factory
        from sqlalchemy import text
        factory = get_session_factory()
        async with factory() as session:
            url = str(session.get_bind().url)

        jobstore = SQLAlchemyJobStore(url=url)
        self._sched = AsyncIOScheduler(jobstores={"default": jobstore}, timezone=self._config.timezone)
        for s in self._repo.list_active():
            self._add_or_replace(s)
        self._sched.start()
        logger.info("[Scheduler] started with %d active schedules", len(self._repo.list_active()))

    async def stop(self) -> None:
        if self._sched is not None:
            self._sched.shutdown(wait=False)
            self._sched = None

    def add_schedule(self, schedule) -> None:
        if self._sched is None:
            return
        self._add_or_replace(schedule)

    def remove_schedule(self, schedule_id: str) -> None:
        if self._sched is None:
            return
        job_id = self._job_id(schedule_id)
        try:
            self._sched.remove_job(job_id)
        except Exception:
            logger.exception("[Scheduler] remove_job failed for %s", schedule_id)

    def trigger_now(self, schedule_id: str) -> None:
        if self._sched is None:
            return
        try:
            self._sched.modify_job(self._job_id(schedule_id), next_run_time=datetime.now(timezone.utc))
        except Exception:
            logger.exception("[Scheduler] trigger_now failed for %s", schedule_id)

    def list_due(self, now: datetime) -> list[str]:
        # Used by tests; reads apscheduler's view.
        if self._sched is None:
            return []
        out = []
        for job in self._sched.get_jobs():
            if job.next_run_time and job.next_run_time <= now:
                out.append(job.id.replace("sched:", ""))
        return out

    def _job_id(self, schedule_id: str) -> str:
        return f"sched:{schedule_id}"

    def _add_or_replace(self, s) -> None:
        if s.kind == ScheduleKind.CRON:
            tz = ZoneInfo(s.cron_tz or self._config.timezone)
            trigger = CronTrigger.from_crontab(s.cron_expr, timezone=tz)
        else:
            assert s.run_at is not None
            trigger = DateTrigger(run_date=s.run_at, timezone=ZoneInfo(self._config.timezone))
        self._sched.add_job(
            self._on_fire,
            trigger=trigger,
            args=[s.id],
            id=self._job_id(s.id),
            replace_existing=True,
            coalesce=self._config.apscheduler.coalesce,
            max_instances=self._config.apscheduler.max_instances,
            misfire_grace_time=self._config.apscheduler.misfire_grace_seconds,
        )
        # Persist job id + next fire.
        job = self._sched.get_job(self._job_id(s.id))
        next_fire = job.next_run_time if job else None
        self._repo.update(s.id, {"apscheduler_job_id": self._job_id(s.id), "next_fire_at": next_fire})
```

# backend/app/scheduling/formatting.py
from __future__ import annotations

def format_push_message(schedule, attempt: int, status: str, body: str, run_url: str | None, max_length: int) -> str:
    title = schedule.title
    prefix = ""
    if status == "success":
        prefix = f"📅 {title}（尝试 {attempt}）\n"
    elif status == "retry":
        prefix = f"🔄 重试 ({attempt}/3)\n📅 {title}\n"
    elif status == "failed":
        prefix = f"❌ {title} 失败：{body}\n"
        body = ""
    else:
        prefix = f"📅 {title}\n"
    suffix = f"\n{run_url}" if (run_url and status in ("success", "failed", "retry")) else ""
    text = prefix + body + suffix
    if len(text) > max_length:
        text = text[: max_length - 50] + "\n…(内容截断)…" + (suffix if status == "success" else "")
    return text
```
